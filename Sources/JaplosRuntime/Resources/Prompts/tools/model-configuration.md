For current model configuration, visibility of settings, or the current thinking policy,
call runtime.model.configuration.get once and answer from its result. It includes the
current route, endpoint, credential-configured status and thinking revision without a
network refresh. Do not also call current/list/search or inspect configuration directories.
Null fields mean unavailable through this interface; state that limit without hunting files.
Current declarations and returned configuration override historical assistant claims about
missing settings. To change the current model's thinking policy, use this lookup followed
by runtime.model.thinking.set with the returned current IDs and thinking revision.
